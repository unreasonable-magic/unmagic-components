Combobox

A text input that filters a list of options, choosing one or several, with the list served from a collection or fetched as you type. The ARIA combobox pattern, with the list in the top layer so nothing clips it.

New in 0.6.0 combobox import "unmagic/components/combobox" 3 examples

One of a list

Type to filter; arrow keys move, Enter chooses, Escape restores. The value is a hidden input, so a form submitted before script loads keeps it.
