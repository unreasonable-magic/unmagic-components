Nested folders and a long path

Folders open and fold, and come before the files beside them. A folder that holds only a folder joins it in one row, which shortens from the front so the last folder's name stays; a long file name truncates only when it alone doesn't fit. Each row's title is its full path. The count is the number of files.

<%# A host's warm greys, scoped to this panel: the neutral ramp redefined on the
    wrapper, at the same lightness as Tailwind's so every text pair keeps its
    contrast. In an app this rule lives in your Tailwind input file. %>
<% warm_greys = {
  50 => "98.5% 0.004", 100 => "97% 0.007", 200 => "92.2% 0.012", 300 => "87% 0.016",
  400 => "70.8% 0.024", 500 => "55.6% 0.03", 600 => "43.9% 0.028", 700 => "37.1% 0.025",
  800 => "26.9% 0.02", 900 => "20.5% 0.016", 950 => "14.5% 0.012"
}.map { |shade, value| "--color-neutral-#{shade}: oklch(#{value} 70);" }.join(" ") %>

    <% plan.step "Gather references", state: :completed %>

  <% end %>

    <% workspace.file "scene.json", size: 6_120 %>
    <% workspace.file "notes.md", size: 812, icon: :pencil %>
  <% end %>
</div>
