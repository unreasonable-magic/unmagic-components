Context menu

The same panel as menu, opened at the pointer on a right-click or a long press on the element it is for, or at its corner on Shift+F10. The element can sit anywhere, so a table row can have one.

context_menu import "unmagic/components/menu" 1 example

On table rows

Right-click a row, or long-press it on a phone. Keep the actions reachable elsewhere too: without script the browser's own menu shows.

<%= table_for @things, id: "ctx_things" do |table| %>
  <% table.column "Name" do |thing| %>
    <span id="<%= dom_id(thing, :ctx) %>" class="block cursor-context-menu"><%= thing.name %></span>
    <%= context_menu for: dom_id(thing, :ctx), label: "#{thing.name} actions" do |menu| %>
      <% menu.link "Open", "#", icon: :file %>
      <% menu.link "Copy link", "#", icon: :copy %>
      <% menu.divider %>
      <% menu.button "Delete", "#", method: :delete, tone: :danger, icon: :x %>
    <% end %>
  <% end %>
  <% table.column "Score", :score, numeric: true %>
<% end %>
