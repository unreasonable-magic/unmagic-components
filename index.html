Components Overview

unmagic-components for Rails

Server-rendered UI components for Rails views, in the spirit of form_for: describe the columns, the fields or the tabs, and get the chrome. Styled with Tailwind CSS v4, with behaviour from plain custom elements and no Stimulus.
